# Изменения

## 2.2 — 24 октября 2026

- Команды `/setplan` и `/delplan`: план по позициям меняется прямо из бота, без правки `plan.json`.
- Бот сам сообщает, когда цена пробила уровень выхода из плана (лонг — вниз, шорт — вверх). Одно сообщение
  на пробой; если цена вернётся за уровень, напоминание снова включится.
- В обзоры брокеров больше не попадают развлекательные посты: длинный пост без ваших бумаг и макро-тем
  проходит, только если в нём есть хотя бы два «рыночных» слова (акции, дивиденды, отчётность, % и т. п.).

## 2.1 — 24 октября 2026

- Постоянное меню кнопками под строкой ввода вместо кнопок в сообщениях.
- Несколько пользователей: владелец открывает доступ командой `/adduser`, у каждого свои портфель, план и отчёты.
- План по позициям (`data/plan.json`, команда `/plan`) с проверкой уровней выхода в каждом отчёте.
- `start_bot.bat` для автозапуска в Windows с перезапуском после сбоя.

## 2.0.1 — 23 октября 2026

- Макро-раздел стал точнее: больше не ловит «1 млн рублей», «ставки» в казино и «углекислый газ».
- Одна новость из нескольких лент (Интерфакс в Telegram и в RSS) показывается один раз.
- Из обзоров убраны опросы, мемы и служебные посты «pinned a photo».
- `check_sources.py --apply` больше не включает источники, выключенные по умолчанию (ТАСС, Лента.ру).
- Проверка дивидендов идёт через API Т-Инвестиций; ложный совет про VPN для iss.moex.com убран.

## 2.0 — октябрь 2026

**Новости без ручного копирования**
- Бот сам читает открытые Telegram-каналы через `t.me/s/…` и запоминает последний прочитанный пост,
  поэтому между отчётами ничего не теряется. Каналы и RSS-ленты настраиваются в `config/sources.json`.
- Обзоры брокеров (Альфа-Инвестиции, СберИнвестиции, БКС) попадают в отчёт целиком, ленты новостей —
  только упоминаниями ваших бумаг и макро-тем.
- Пересланные посты, ссылки, текст и файлы `.txt`/`.html` сохраняются как «ваши материалы».
  Из скопированных страниц убирается мусор: меню, комментарии, форма открытия счёта, подвал, повторы.

**Портфель**
- Команды `/buy`, `/sell`, `/pos`: средняя цена, зафиксированный результат, шорт при продаже сверх позиции.
- В отчёте: результат по каждой позиции, итог, риск шорта, дивиденды на ваши акции и предупреждение
  о дивиденде для шорта.

**Рынок и индикаторы**
- RSI(14), SMA20/50/200, ATR(14), годовой диапазон, объём предыдущей полной сессии.
- Нефть Brent (фьючерс на Мосбирже), ключевая ставка ЦБ, индекс гособлигаций RGBI.
- Раздел «Техническая картина»: положение цены словами, без прогнозов.

**Удобство**
- Отчёты в заданное время (`REPORT_TIMES`, по умолчанию 10:05, 16:05, 19:05 по будням) вместо каждого часа.
- Уведомления об уровнях `/alert NVTK 1170`.
- Проверка источников `/check` и `python check_sources.py --apply` с советами по VPN и сертификатам.
- Копии отчётов в `data/reports/`, отчёт «с прошлого отчёта» вместо «за 7 дней».
- Пути считаются от папки проекта, файлы пишутся безопасно (через временный файл).

**Перенос со старой версии**
- `data/sources.json` и `data/sources_candidates.json` заменены на `config/sources.json`.
- `auto_report.py` и `tinkoff_extras.py` встроены в `scheduler.py` и `tinkoff_client.py`.
- Старые настройки `.env` продолжают работать: `REPORT_INTERVAL=0` выключает автоотчёты,
  `REPORT_TRADING_HOURS` понимается как `REPORT_WEEKDAYS_ONLY`.
- `data/watchlist.json`, `data/portfolio.json` и `data/last_prices.json` остаются в том же формате.
