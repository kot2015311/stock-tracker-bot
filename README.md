# Stock Tracker Bot

[English version](README.en.md) · ![tests](https://github.com/kot2015311/stock-tracker-bot/actions/workflows/tests.yml/badge.svg)

Телеграм-бот для частного инвестора на Мосбирже. Следит за ценами и портфелем (включая шорты),
сам собирает новости из Telegram-каналов брокеров и новостных лент и по расписанию присылает
отчёт-файл: портфель, рынок, цены с техническими индикаторами, дивиденды, новости по вашим бумагам
и обзоры аналитиков.

*A Telegram bot for a retail investor on the Moscow Exchange: portfolio P&L with shorts, price alerts,
automatic news collection from public Telegram channels and RSS, scheduled analytical reports.*

## Возможности

- **Отчёт по расписанию** (по умолчанию 10:05, 16:05, 19:05 по будням) и по кнопке. Внутри:
  - портфель: результат по каждой позиции, зафиксированный и текущий результат, риск шорта;
  - рынок: индекс МосБиржи, RGBI, нефть Brent (фьючерс на Мосбирже), курсы ЦБ, ключевая ставка;
  - цены и динамика: день, 5 и 20 дней, диапазон, RSI(14), положение относительно SMA50 и SMA200, объём;
  - техническая картина словами: «у нижней границы 20-дневного диапазона», «RSI 28 — перепроданность»;
  - дивиденды: объявленные выплаты с датой «купить до» и суммой на ваши акции, предупреждение для шорта;
  - новости по вашим бумагам за 3 дня, обзоры брокеров целиком, макро-новости, ваши материалы.
- **Новости без копирования**: бот читает открытые Telegram-каналы (Альфа-Инвестиции, СберИнвестиции,
  БКС, MarketTwits, Интерфакс, ЦБ, РБК) через веб-просмотр `t.me/s/…` и RSS-ленты. Вход в Telegram-аккаунт не нужен.
- **Ваши материалы**: перешлите боту пост, пришлите ссылку, текст или файл `.txt`/`.html`.
  Бот достанет текст статьи и уберёт мусор: меню, комментарии, форму открытия счёта, подвал, повторы.
- **Портфель командами**: `/buy`, `/sell` (продажа сверх позиции открывает шорт), `/pos`. Средняя цена
  и зафиксированный результат считаются сами.
- **Уведомления**: о движении цены на заданный процент, о достижении уровня (`/alert NVTK 1170`)
  и о пробое уровня выхода из плана (`/setplan`): для лонга — вниз, для шорта — вверх, один раз на пробой.
- **Проверка источников** `/check`: что доступно из вашей сети, а что блокируется, и что с этим делать.

Бот показывает данные и факты. Решения о сделках принимаете вы: это не инвестиционная рекомендация.

## Как это устроено

```
 Telegram-каналы (t.me/s) ─┐
 RSS-ленты ────────────────┼─► сборщик новостей (раз в 10 мин) ─► data/news_store.json ─┐
 ваши пересланные посты ───┘                                                           │
                                                                                       ▼
 Т-Инвестиции API (цены, дивиденды) ─┐                                          сборка отчёта ─► файл в Telegram
 ISS Мосбиржи (свечи, Brent) ────────┼─► индикаторы ─────────────────────────────►     ▲
 ЦБ РФ (курсы, ключевая ставка) ─────┘                                                 │
 data/portfolio.json (/buy, /sell, /pos) ──────────────────────────────────────────────┘
```

## Установка

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/kot2015311/stock-tracker-bot.git
cd stock-tracker-bot
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # macOS и Linux
pip install -r requirements.txt
```

**SDK Т-Инвестиций** (пакет `t-tech-investments`, импорт `t_tech.invest`) ставится отдельно.
Т-Банк публикует его в своём репозитории пакетов, а копия на PyPI с января 2026 года заблокирована:

```bash
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple
```

Если ругается на сертификат, добавьте `--trusted-host opensource.tbank.ru`. Если репозиторий не отвечает,
поставьте SDK из сохранённого файла: `pip install t_tech_investments-<версия>-py3-none-any.whl`.
Документация API: [developer.tbank.ru/invest](https://developer.tbank.ru/invest).

**Настройки.** Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → `/newbot` |
| `TINKOFF_TOKEN` | Т-Инвестиции → Настройки → Токены API → «Выпустить токен», доступ **«Только чтение»** |
| `OWNER_ID` | ваш Telegram ID, например через @userinfobot |

Остальные переменные необязательны, их описание есть в `.env.example`.

**Проверка источников и запуск:**

```bash
python check_sources.py --apply    # что доступно из вашей сети; включит рабочие источники
python main.py
```

В Telegram отправьте боту `/start`.

**Автозапуск в Windows.** `start_bot.bat` запускает бота и перезапускает его после сбоя.
Чтобы бот стартовал вместе с компьютером, нажмите Win+R, введите `shell:startup` и положите туда ярлык на `start_bot.bat`.

### Если что-то не открывается

- **Российские сайты** (`iss.moex.com`, `cbr.ru`, ленты новостей) часто не пускают зарубежные IP.
  Если включён VPN, добавьте для этих доменов правило «Прямое» (без VPN).
- **Telegram** (`t.me`, `api.telegram.org`), наоборот, может требовать VPN.
- **Ошибка сертификата**: положите `ca_bundle.pem` (обычные сертификаты плюс корень Минцифры) в папку
  проекта или рядом с ней либо укажите путь в `CA_BUNDLE`. Он нужен и gRPC (Т-Инвестиции), и HTTP.
- `python check_sources.py` или `/check` в боте покажут, что именно не работает и почему.

## Команды бота

Главное меню — кнопки внизу экрана, под строкой ввода: отчёт, портфель, план, новости, уровни, материалы,
список бумаг, цена, добавить, удалить, проверка, помощь. Если кнопки пропали, отправьте `/menu`.

| Команда | Что делает |
|---|---|
| `/report` | отчёт сейчас |
| `/portfolio` | позиции и результат по текущим ценам |
| `/buy SBER 10 291.5` | покупка (или закрытие шорта); цену можно не писать — возьмётся текущая |
| `/sell NVTK 13 1124` | продажа; если продать больше, чем есть, остаток станет шортом |
| `/pos NVTK -5 1124` | задать позицию вручную (минус — шорт, `0` — удалить) |
| `/alert NVTK 1170` | сообщить, когда цена дойдёт до уровня |
| `/alerts`, `/unalert NVTK` | список уровней, удаление |
| `/plan` | план по позициям: действие, уровень выхода, не пробит ли он |
| `/setplan GMKN 112 держать` | задать план по бумаге (уровень можно заменить на `-`) |
| `/delplan GMKN` | убрать бумагу из плана |
| `/news`, `/news SBER` | свежие упоминания ваших бумаг |
| `/inbox` | материалы, которые вы прислали |
| `/check` | проверка источников из вашей сети |

## Несколько пользователей

Бот частный: отвечает владельцу (`OWNER_ID`) и тем, кому владелец открыл доступ.
1. Человек пишет боту `/start` — бот отвечает его Telegram ID.
2. Владелец отправляет `/adduser <ID>`. Список — `/users`, закрыть доступ — `/deluser <ID>`.

У каждого пользователя свой список наблюдения, портфель, план, уровни и отчёты в `data/users/<ID>/`
(у владельца — прямо в `data/`). Новости из каналов и лент общие, присланные материалы видны только автору.
Каждый может запустить и свою копию бота: склонировать репозиторий и заполнить свой `.env`.

**Свои материалы.** Всё, что не команда, бот сохраняет для следующего отчёта:
пересланный пост канала, ссылку на статью (бот скачает текст), скопированный текст страницы,
файл `.txt`, `.md` или `.html`.

Пример: было 8 акций NVTK по 1137, вы продали 13 по 1124. Команда `/sell NVTK 13 1124` запишет
зафиксированный результат по восьми акциям (1124 − 1137) × 8 = −104 ₽ и откроет шорт на 5 акций по 1124.

## Настройка источников

`config/sources.json` — Telegram-каналы и RSS-ленты:

```json
{"channel": "alfa_investments", "name": "Альфа-Инвестиции", "kind": "analytics", "enabled": true}
```

- `kind: "analytics"` — обзоры брокеров, в отчёт попадают целиком (всё, что вышло с прошлого отчёта);
- `kind: "feed"` — ленты новостей, в отчёт попадают только упоминания ваших бумаг и макро-тем;
- подходит любой открытый канал, у которого работает страница `https://t.me/s/<канал>`.

`config/keywords.json` — по каким словам искать новости о бумагах. Пишутся основы слов
(«норникел» найдёт «Норникель» и «Норникеля»). Для бумаг, которых там нет, бот ищет по тикеру
и названию компании.

## Где лежат данные

Папка `data/` создаётся сама и в git не попадает:

| Файл | Что в нём |
|---|---|
| `watchlist.json` | список наблюдения: тикер, FIGI, опорная цена, порог уведомления |
| `portfolio.json` | позиции: количество, средняя цена, зафиксированный результат (образец в `examples/`) |
| `trades.json` | журнал сделок из `/buy` и `/sell` |
| `alerts.json` | уровни из `/alert` |
| `news_store.json` | собранные новости и ваши материалы (ленты — 3 дня, обзоры — 7, ваши — 14) |
| `reports/` | копии всех отчётов в `.txt` и цифры в `.json` за 60 дней |

## Тесты

Тесты работают без интернета и без токенов: сеть и биржа в них подменяются подделками.
GitHub запускает их сам при каждом push (`.github/workflows/tests.yml`).

```bash
python -m unittest discover -s tests -v
```

Реальную доступность источников проверяет `python check_sources.py`.

## Безопасность

- Токен Т-Инвестиций выпускайте только с правом «Только чтение»: бот не торгует.
- `.env`, сертификаты и папка `data/` перечислены в `.gitignore`. Не выкладывайте их.
- Если токен попал в чат или на GitHub, сразу перевыпустите его: в Т-Инвестициях удалите старый токен,
  в @BotFather выполните `/revoke`.
- Бот отвечает только пользователю с `OWNER_ID`.

## Ограничения

- Комиссии брокера и плата за перенос шорта в результате не учитываются.
- Веб-просмотр работает только для открытых каналов, и Telegram может его изменить. Если канал
  перестал читаться, `/check` это покажет.
- Используйте источники в рамках их правил: для личного пользования бот берёт текст постов
  и заголовки со ссылками.
